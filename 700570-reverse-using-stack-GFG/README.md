# [Reverse Using Stack](https://www.geeksforgeeks.org/problems/reverse-a-string-using-stack/1?page=2&category=Java,Stack&sortBy=submissions)
## Easy
You are given a string s , the task is to reverse the string using stack.
Examples:
Input: s ="GeeksforGeeks"
Output:  skeeGrofskeeG
Input: s ="Geek"
Output: keeG
Constraints:1 ≤ s.length() ≤ 100
